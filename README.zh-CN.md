# IconLib

IconLib 是一个用来查找和保存 App Store 应用图标的小工具。输入应用名称，或者直接粘贴 App Store 链接，就能看到应用的高清图标、截图和基本信息，并一键存到相册。

## 能做什么

- 按名称搜索，或粘贴 `apps.apple.com` 链接直接打开对应应用
- 保存 256 / 512 / 1024 像素的无损 PNG 图标，也可以直接保存原图；可选圆形、微圆角或自定义圆角
- 查看并保存应用截图，顺便看看 Bundle ID、当前版本、更新内容和最低系统要求
- 右上角切换 App Store 地区，默认中国区
- 界面支持简体中文、English 和 Tiếng Việt

## 运行要求

iOS 15 及以上
