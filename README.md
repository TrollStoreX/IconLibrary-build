# IconLib

IconLib is a little tool for grabbing App Store app icons. Search by name or paste an App Store link, and you'll get the full-size icon, screenshots and a few basic details, ready to save to your Photos.

## What it does

- Search by name, or paste an `apps.apple.com` link to jump straight to the app
- Save icons as lossless PNG at 256, 512 or 1024 px, or keep the untouched original; circle, slightly rounded or custom corners if you want them
- Browse and save screenshots, and check the bundle ID, current version, release notes and minimum iOS
- Switch App Store region from the top-right corner (China by default)
- English, Simplified Chinese and Vietnamese

## Requirements

iOS 15 or later
